Cluster tooling

Cbench

Scalable cluster benchmarking and testing toolkit. Automates the full lifecycle of HPC benchmarking — generating job scripts, submitting them to the batch scheduler, and parsing output into structured results across 31 benchmarks. Originally from Sandia National Laboratories; v2 adds a modern Python toolchain alongside the original Perl.

PerlPythonBenchmarking

CAP — Cluster Administration Package

A framework that integrates, configures, and manages HPC clusters by bundling common cluster tools — pdsh, genders, Slurm, munge, conman, freeipmi, powerman — behind a unified build and install system with RPM and Debian packaging.

ShellPackagingCluster ops

IBM Storage Scale

Scale GUInstall

A single-file web frontend for the IBM Storage Scale Installation Toolkit. Gives a guided, form-driven interface for installing, deploying, and upgrading Scale clusters, with a command preview before anything runs. Ships as signed RPM and DEB packages.

HTMLFlaskInstaller

Network Readiness (KOET)

Development fork of the IBM Storage Scale network readiness tool. Validates cluster interconnect health — latency, throughput, and packet loss — before a Scale deployment goes anywhere near production.

CNetworkingValidation

Storage Scale MCP Server

An MCP server built on the IBM Storage Scale REST APIs and CLIs, letting LLMs query and interact with a live Scale cluster through a structured tool interface.

PythonMCPFork

ESS Comprestimator

IBM Storage Scale System compression estimator — samples existing data to project how much capacity compression would actually reclaim before you commit to enabling it.

TypeScriptCapacityFork
